# Human-Centered Art Direction

Skill для Claude Code и Codex: помогает придумать визуальный язык сайта, бренда или контента с опорой на задачу, аудиторию и реальные материалы. Сначала изучает проект и предлагает три разные арт-концепции, затем запрашивает нужные фотографии и только после выбора направления переходит к дизайну.

Автор: Екатерина Бабочкина. Версия 1.0.

Лицензия: [MIT](LICENSE). Она распространяется на файлы этого репозитория; материалы сторонних источников по ссылкам сохраняют свои условия использования.

## Что внутри

- [`SKILL.md`](SKILL.md) — основной рабочий процесс арт-директора.
- [`references/style-library.md`](references/style-library.md) — девять визуальных направлений и их ограничения.
- [`references/typography.md`](references/typography.md) — выбор и проверка кириллических шрифтов.
- [`references/quality-rubric.md`](references/quality-rubric.md) — оценка результата по шести критериям.
- [`references/sources.md`](references/sources.md) — первоисточники и границы их применения.
- `templates/` — вопросы для брифа, список нужных фотографий и шаблон передачи концепции в работу.

## Установка

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив. Переименуй распакованную папку в `human-centered-art-direction`.
2. Скопируй **всю папку**, включая `references/` и `templates/`, в каталог навыков нужной программы:

| Программа | Для одного проекта | Для всех локальных проектов |
| --- | --- | --- |
| Claude Code | `<проект>/.claude/skills/human-centered-art-direction/` | `~/.claude/skills/human-centered-art-direction/` |
| Codex | `<проект>/.agents/skills/human-centered-art-direction/` | `~/.agents/skills/human-centered-art-direction/` |

Внутри конечной папки должен лежать `SKILL.md`, рядом с `references/` и `templates/`. Открой новый сеанс агента после копирования.

Пути сверены с документацией [Claude Code](https://code.claude.com/docs/en/skills) и [Codex](https://learn.chatgpt.com/docs/build-skills). Локальная установка не переносит Skill автоматически в облачный чат.

## Первый запрос

В Claude Code можно вызвать `/human-centered-art-direction`, в Codex — `$human-centered-art-direction`, либо написать название навыка в запросе:

> Используй Human-Centered Art Direction. Хочу создать сайт для моего проекта. Сначала изучи мой бизнес и материалы, предложи три разные арт-концепции и скажи, какие реальные фотографии нужны. После выбора направления помоги сделать дизайн.

Подготовь краткий рассказ о проекте, целевой аудитории и задаче дизайна. Если есть, приложи логотип, тексты, фотографии, ссылку на сайт и примеры того, что нравится или не нравится. Дальше выбери одну концепцию или попроси сочетать две.

## Важные границы

Это набор инструкций, а не генератор изображений или подключение к Canva, Figma, Adobe и другим сервисам. Доступные действия зависят от инструментов агента. В репозитории нет чужих фотографий, шрифтов и дизайн-макетов. Упомянутые исследования и проекты служат источниками идей, а не готовыми шаблонами; права на конкретные изображения и шрифты нужно проверять отдельно.
