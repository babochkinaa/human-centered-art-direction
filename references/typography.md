# Typography / Шрифтотека
- Discover font candidates: https://myskotom.ru/shriftoteka (catalog claims 1700+ Cyrillic typefaces usable commercially; listings exclude Google Fonts). Catalog inclusion does not replace verification of individual font license and webfont rights.
- Get 3 candidate combinations with reason: heading personality; comfortable body copy; numbers/CTA if needed. A single family is often best.
- Check Cyrillic А–Я, Ё/ё, punctuation, weights, small-size rendering, contrast, line lengths, line-height and mobile layout. Write a test sentence containing Ё, Й, Ъ, Ь and numerals.
- Validate current rights at original font source; note author/license/version and embed allowance. Avoid sending distributing font binaries; link to licensed sources.
- Document fallback stacks if fonts are unavailable. No automatic claims that unusual typeface supports Cyrillic.
- For each direction provide type scale desktop/mobile and hierarchy tokens; test on real copy, not lorem ipsum.
